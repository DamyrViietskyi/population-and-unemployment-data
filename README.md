# Population and Unemployment Data

**Stack:** Python · pandas · Jupyter

How can two wide statistical tables be prepared for analysis?

## Analysis

Reshape World Bank population and Eurostat unemployment data, preserve observation flags, and calculate unemployment gaps by sex.

## Run locally

Install dependencies with `python -m pip install -r requirements.txt`. Place authorized copies of the input files at: data/world_bank_population.csv, data/une_rt_a.tsv. Open `analysis.ipynb` in Jupyter and run it from the repository root. Input datasets are excluded.

Developed from STAT163 coursework at Kyiv School of Economics.
